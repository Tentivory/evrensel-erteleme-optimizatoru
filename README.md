# Evrensel Erteleme Optimizatörü

## Özet

Bu proje, modern insanın en büyük mücadelesi olan **erteleme sanatını** bilimsel temellere oturtmak amacıyla geliştirilmiştir. Yıllar süren (aslinda 3 dakika) araştırmalar sonucunda, herhangi bir görevin optimal başlama zamanının **her zaman yarın sabah, kahveden sonra** olduğu kanıtlanmıştır.

Bu algoritma, kozmik ışınlar, komşunun köpeğinin havlama frekansı ve varoluşsal korku seviyesi gibi kritik parametreleri dikkate alarak %99.7 doğruluk oranıyla sonuç üretir.

## Özellikler

- Gerçekten çalışır (deneyin, göreceksiniz)
- Bilimsel görünümlü çıktılar üretir
- Erteleme suçluluğunuzu azaltır
- Hiçbir şey yapmaz ama çok şey yapmış gibi hissettirir

## Kurulum ve Kullanım

```bash
python main.py
```

Bu kadar. Başka bir şeye gerek yok. Zaten erteleyeceksiniz.

## Bilimsel Temel

Algoritma, şu denklem üzerine kuruludur:

$$ O = \max(Yar\u0131n, Kahve) $$

Burada $O$ optimal zamandır. Diğer tüm değişkenler gürültüdür.
